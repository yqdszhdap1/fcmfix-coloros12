# FCMFix ColorOS 13.2.4

## 更新内容
1. **修复分身应用（MultiApp / 次要用户）收不到 FCM 推送的问题**：
   - 此前 FCM 投递窗口与 Hans 解冻都按 `getPackageUid(pkg, 0)` 解析目标 UID，只认主空间。
     ColorOS MultiApp 把同一包名装在克隆用户（如 user 999）下，UID 不同，于是广播虽然
     投递到了分身进程，20 秒后台网络窗口和解除冻结却都给了主空间，分身仍处于冻结状态，
     推送被丢弃——表现为「消息延迟一分钟，亮屏才补收」。
   - 现按包名解析出该应用**所有已安装用户**的 UID（主空间优先），逐一开启投递窗口与解冻，
     分身与主空间同时覆盖。
   - 新增 `getTargetUidsFromPackageName()` 与 `getTargetUidFromPackageName(pkg, userId)`；
     `beginFcmDeliveryWindow()` / `unfreeze()` 均增加 userId 重载（`-1` 表示覆盖全部安装）。

## 说明
- 仅影响 FCM 投递窗口与解冻的目标解析；GMS 联网修复等主空间专用链路保持不变。
- 主空间行为与 13.2.3 一致（单安装时仍解析到同一 UID）。
