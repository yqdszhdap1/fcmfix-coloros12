# FCMFix ColorOS 13.2.2 (一加 7 Pro / ColorOS 12.1 专配版)

专为一加 7 Pro (GM1910) / ColorOS 12.1+ 系统量身定制的无感叹号专配版。

## 适配更新
1. **适配系统类与方法**：
   - `OplusProxyBroadcast`：兼容匹配 `shouldProxyLocked` 方法与直接参数提取，完美放行 FCM 广播。
   - `OplusProxyWakeLock`：适配 `unproxyWakeLock` 与 `OplusHansManager#unFreezeForwl` 真实唤醒解冻通道。
2. **剔除高版本不适用的冗余检测**：
   - 安全跳过 ColorOS 12.1 未引入的 `MaliciousRestrictPolicy`、`OplusLinkStartManager`、`BroadcastProxyAction` 等类，消除失配项。
   - 电池与网络组件消除 `OAppNetControlManager` 相关失配。
3. **修复自检与告警**：
   - GMS/GSF 基础服务不再误报“通知已关闭”，彻底做到首页状态“一切正常”，零感叹号。
